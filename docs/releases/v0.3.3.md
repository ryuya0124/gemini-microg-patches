# v0.3.3

Fix Google crashing at startup with `VerifyError: register index out of range (1 >= 1)` after patching in Android Morphe Manager.

Process-name normalization now uses a helper with an explicit register layout instead of changing a private Patcher field. This works with Manager2.5.0 / Patcher2.3.0 and preserves the cached-return fix and default clone setup.

Before publication, both v0.3.2 and v0.3.3 were built through the actual Android Manager GUI from the same original Google APK. Android12 reproduced the reported error with v0.3.2 and passed the fixed provider/cache/widget/startup checks with v0.3.3. The existing API31/API36 regressions also passed 26 assertions each, plus all 11 MPP configuration checks. [Details and reproduction](https://github.com/ryuya0124/gemini-microg-patches/blob/main/docs/testing/issue-8-manager-registers.md).

Update this patch source, then repatch the original Google APK with the default selection. Keep your existing Manager signing key for an in-place update. Supported APK versions and minimum SDKs are unchanged. No Google APKs or signing keys are included. Emulator login/chat and the reporter's physical device were not tested.
