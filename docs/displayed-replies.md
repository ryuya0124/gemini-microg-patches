# 表示済みの回答を保持する（試験機能）

Google `17.72.17.ve.arm64` / versionCode `301831138` 用です。試験版MPPで **Preserve displayed replies** を追加選択してGoogleアプリにパッチします。初期選択はオフです。Geminiランチャーへの追加パッチは不要です。

チャット画面の「保持した回答」から、表示済みの本文と画像を閲覧できます。本文が後で置き換わったり、元の表示が消えたりしても、保存が完了した内容はアプリ再起動後も残ります。保持した本文は選択・コピーできます。

動画も対象です。「動画も保存する」を有効にすると、表示中の生成動画の取得を試みます。通信が発生する場合があります。取得が完了した動画は、元のリンクが期限切れになっても保持画面から再生できます。取得前にリンクが利用できなくなった場合や、対応していない配信形式では保存できません。

画像は画面に読み込まれたデータから保存し、長辺2,048ピクセルまでに縮小します。元の生成ファイルそのものと同じ解像度になるとは限りません。本文・画像・動画とも、表示されなかった内容やサーバーが送信しなかった内容は保存できません。短時間の表示などで取得し損ねる場合もあります。

## 保存と消去

- アプリ専用のバックアップ対象外領域へ暗号化して保存します。自動アップロードはありません。
- Googleの会話履歴とは別の保存です。会話を切り替えたりログアウトしたりしても保持されます。
- 「保持を一時停止」は新しい保存を停止し、保存済みデータを残します。
- 「消去して一時停止」は保持した本文・画像・動画を削除して保存を停止します。「保持を再開」で再開できます。
- アプリのデータ消去・アンインストールで保持データも失われます。同じ署名による通常の更新では保持領域を引き継ぎます。

本文は最新8版・各32,768文字・合計131,072文字までです。画像と動画は合計8ファイル・128 MBまで、画像は保存後8 MBまで、動画は1件32 MBまでです。上限を超えると古い保存を順に削除します。動画取得失敗は保持画面に表示します。

この機能は表示済みデータのローカル保存です。サーバーの生成判断やGoogle側の会話履歴を変更する機能ではありません。

開発者向けの対象ビュー、更新時の探索方法、検証範囲は[開発記録](../diagnostics/displayed-replies.md)を参照してください。
